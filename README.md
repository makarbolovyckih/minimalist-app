# Blank (text-only launcher widget)

1. Create a new GitHub repo, upload everything in this folder (keep the `.github` folder), push to `main`.
2. Repo > Actions > "Build IPA" > wait for green. The log says whether the iOS 27 extra-large widget was included.
3. Download the `Blank-ipa` artifact, unzip, drag `Blank.ipa` into Sideloadly, sign with your Apple ID.
4. Add the widget, long-press > Edit Widget, fill Link 1-10 as `Label|url`.

Free Apple ID: re-sign every 7 days.
